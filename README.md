# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/aman07052005/CodeAlpha_Tasks.git
```

## Navigate to a Project

```bash
cd Task-1-ShopNest-Ecommerce
```

## Install Dependencies

```bash
npm install
```

## Start Backend

```bash
npm run server
```

## Start Frontend

```bash
npm start
```
